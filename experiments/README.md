# Эксперименты

Здесь лежат воспроизводимые измерения к разбору. Они не заменяют стенды из
[§11](../docs/4-checks/11-stands.md) и не претендуют на роль исследования
антифрод-движка: это проверка конкретных утверждений о том, что видит сервер.

| Эксперимент | Что проверяет | Где используется |
|---|---|---|
| [syn-and-rtt-gap](syn-and-rtt-gap/README.md) | зазор `ACK → ClientHello` на прямом пути, через CONNECT и SOCKS5; что видит сервер, когда на клиенте локальный TUN-прокси | [§0](../docs/2-network/00-two-realities.md), [§3](../docs/2-network/03-p0f-ja4t.md), [§5](../docs/2-network/05-rtt.md), [§11](../docs/4-checks/11-stands.md) |

Общие правила для всех экспериментов:

- IP-адреса в опубликованных выводах заменены на документационные диапазоны
  (`192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`); сырые pcap не публикуются.
- В каждом отчёте зафиксированы версии ОС, ядра, Python, curl и дата прогона.
- «В нашем прогоне» означает ровно это: один стенд, одна сеть, одна реализация
  прокси. Результат не выдаётся за свойство «любого прокси».
